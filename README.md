# iot-embedded-journey

物联网工程大一新生的嵌入式硬软双修自学记录。

## 路线图

C语言 → STM32标准库（江协）→ STM32 HAL库（铁头山羊）→ FreeRTOS → Linux/PCB → 电赛

## 目录结构

- `01_c_foundation/` — C语言基础（翁恺课程练习+作业）
- `02_stm32_standard/` — 江协STM32标准库实验
- `03_stm32_hal/` — STM32 HAL库实验
- `04_rtos/` — FreeRTOS学习
- `05_pcb/` — 立创EDA工程文件
- `06_projects/` — 循迹小车、可调电源等项目
- `07_notes/` — 学习笔记、踩坑记录
